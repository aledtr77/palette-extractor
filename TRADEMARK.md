# Trademark and brand

read it, ship it, sell what you build with it.

The **Codedge** name, the logo and the brand marks are not part of that grant.
Trademark is separate from copyright, and an MIT licence does not hand it over;
this file only says out loud what the licence already leaves out.

So: build whatever you like with this code and give it your own name. Don't
present a fork or a derived product as Codedge, and don't use the name or the
logo to identify it.
